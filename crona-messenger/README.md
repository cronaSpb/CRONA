# Crona - Безопасный мессенджер

Приватный мессенджер для небольших команд (до 10 человек) с полным соблюдением законодательства РФ.

## Особенности

- 🔒 **End-to-End шифрование** - полная конфиденциальность
- 🇷🇺 **Соответствие 152-ФЗ** - данные хранятся в РФ
- 👥 **Для малых групп** - оптимизировано для 10 пользователей
- 🛡️ **Полный контроль** - ваш сервер, ваши данные
- ⚡ **Реальное время** - мгновенная доставка сообщений
- 📱 **Веб-интерфейс** - работает в любом браузере

## Технологический стек

### Frontend
- React 18
- TailwindCSS
- Socket.io-client
- Crypto-JS (для E2E шифрования)

### Backend
- Node.js
- Express
- Socket.io
- PostgreSQL
- JWT (аутентификация)
- bcrypt (хеширование паролей)

## Безопасность

- End-to-End шифрование сообщений (AES-256)
- JWT токены для авторизации
- Хеширование паролей (bcrypt)
- HTTPS/TLS для передачи данных
- Rate limiting против спама
- Валидация всех входных данных

## Соответствие законодательству РФ

- ✅ 152-ФЗ "О персональных данных" - хранение на территории РФ
- ✅ 149-ФЗ "Об информации" - регистрация не требуется (<10 пользователей)
- ✅ Политика конфиденциальности
- ✅ Согласие на обработку персональных данных

## Быстрый старт

### Требования
- Node.js 18+
- PostgreSQL 14+
- npm или yarn

### Установка

1. Клонируйте репозиторий
2. Установите зависимости backend:
```bash
cd backend
npm install
```

3. Установите зависимости frontend:
```bash
cd frontend
npm install
```

4. Настройте базу данных PostgreSQL
5. Создайте `.env` файл в папке backend (см. `.env.example`)
6. Запустите миграции БД
7. Запустите backend и frontend

Подробная инструкция в `/docs/INSTALLATION.md`
